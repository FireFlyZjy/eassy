### 🔗 curl：命令行界的“瑞士军刀”

`curl` 是一个极其强大的命令行工具和库，名字是“Client URL”的缩写。它几乎是你与互联网上任何服务器打交道的万能工具。

*   **广泛协议支持**：它不仅支持常见的 HTTP/HTTPS、FTP，还支持 SFTP、SCP、SMTP、POP3、甚至 WebSocket (WS/WSS) 等几十种协议。
*   **强大网络交互**：你可以用它来发送复杂的HTTP请求（如 GET, POST, PUT）、设置请求头、处理cookies、上传或下载文件等。
*   **自动化与调试**：它是自动化脚本和CI/CD流程中不可或缺的一环，也常被开发者用来快速测试API接口，可以看作是命令行的Postman。
*   **常用格式**：`curl [选项] [URL]`

### 📦 npm：Node.js 生态的基石

`npm` (Node Package Manager) 是 Node.js 的官方包管理器，几乎与 Node.js 一同诞生，是 JavaScript 世界不可或缺的工具。

*   **庞大的生态系统**：其官方仓库（registry）拥有超过200万个开源包，构成了世界上最大的单一语言代码仓库，为开发者提供了丰富的“轮子”。
*   **核心依赖管理**：通过 `package.json` 文件，`npm` 可以智能地管理项目依赖及版本冲突，确保项目在不同环境下的一致性。
*   **脚本运行器**：你可以将项目的构建、测试、启动等复杂任务定义为 `npm run` 脚本，极大地简化了开发和部署流程。
*   **常用格式**：`npm install <package-name>` (安装包), `npm init` (初始化项目)。

### 🚀 bun：为速度而生的现代化工具包

`bun` 是一个新兴的 JavaScript 运行时，旨在成为 Node.js 的直接替代品，核心特点就是“快”。它更像一个集成了多种功能的工具包。

*   **卓越的性能**：`bun` 使用 Zig 语言编写，底层采用苹果的 JavaScriptCore 引擎，启动速度比 Node.js 快数倍，内存占用也更低。
*   **内置开发工具链**：它原生集成了包管理器、打包器(bundler)、转译器、测试运行器等功能，让你无需额外安装 webpack、jest 等工具就能快速开始项目。
*   **良好的兼容性**：`bun` 旨在无缝替换 Node.js，这意味着大多数为 Node.js 编写的现有 npm 包和模块都可以在 `bun` 中直接运行。
*   **常用格式**：`bun install` (安装依赖), `bun run index.ts` (运行脚本)。

### 🍺 brew：macOS 的“软件管家”

`brew` (Homebrew) 是 macOS（和 Linux）上最流行的软件包管理器，被称为“macOS 缺失的包管理器”。

*   **安装系统软件**：你可以通过 `brew` 安装各种原本需要手动下载、编译的命令行工具（如 `wget`, `git`, `python`）、编程语言等。
*   **管理应用与字体**：通过 `brew cask`，它甚至可以帮你安装 Chrome、VS Code 等图形界面应用程序、字体和浏览器插件。
*   **简化安装流程**：告别从网站下载 `.dmg` 文件、拖拽安装的繁琐流程，一个命令即可完成安装、更新和卸载，极大地提升了软件管理效率。
*   **常用格式**：`brew install <package-name>` (安装软件), `brew upgrade` (升级所有软件)。

### 📦 paru：Arch Linux 的“增强型包管理器”

`paru` 是一个面向 Arch Linux 用户的 AUR (Arch User Repository) 助手，同时也是官方包管理器 `pacman` 的封装器。

*   **统一包管理入口**：它的最大优势在于允许用户用一个命令同时从官方仓库和 AUR 搜索、安装和更新软件包，而无需区分包的不同来源。
*   **自动化 AUR 操作**：它自动化了从 AUR 安装软件包的繁琐过程，包括下载 `PKGBUILD`、检查更新、执行编译等。
*   **Rust 编写，设计简洁**：`paru` 基于 Rust 编写，以设计简洁、功能强大、交互极少而著称，是 `yay` 等同类工具的流行替代品。
*   **常用格式**：`paru -S <package-name>` (安装包), `paru -Syu` (系统全面更新)。
