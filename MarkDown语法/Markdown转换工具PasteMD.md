## 1. 项目概述

PasteMD 是一款基于本地 AI 的智能文本格式化工具，能够将剪贴板中的杂乱文本一键转换为结构清晰、格式优美的 Markdown 文档。

PasteMD 主要提供两种核心能力：

- **智能格式化模式**：将任何无结构的文本（会议纪要、代码片段、笔记草稿等）转换为规范的 Markdown 格式
- **Office 粘贴模式**：将 Markdown 或网页内容一键转换为 Word/WPS/Excel 兼容格式，直接粘贴到光标位置

与传统的在线格式化工具不同，PasteMD 完全在本地运行，基于 Ollama 框架和 llama3:8b 模型，所有数据处理都在本地完成，确保数据隐私和安全。


## 2. 工作原理

### 2.1 技术架构

PasteMD 基于以下核心技术构建：

- **Ollama 框架**：提供统一的本地大模型管理接口，自动处理模型下载、版本管理和依赖项
- **Llama 3 模型（8B 参数）**：开源领域语义理解与指令遵循能力最均衡的模型之一，对编程语言语法、日志格式、调试信息等有扎实的识别基础
- **精准 Prompt 工程**：通过精心设计的系统提示词，将模型明确定位为"Markdown 格式化专家"，确保输出稳定、专业

### 2.2 处理流程

```
用户粘贴文本 → AI 模型语义分析 → 自动识别内容结构 → 生成 Markdown → 一键复制使用
```

所有推理全程离线运行，复制的任何内容——包括代码、会议记录、内部数据——全部只在本地内存中流转，不会触碰任何外部网络。


## 3. 核心功能

### 3.1 智能格式转换

PasteMD 能够智能处理多种类型的文本：

- **技术文档**：自动识别参数说明、返回值描述和代码示例，生成带有适当标题层级、代码块和表格的 Markdown
- **会议记录**：自动提取关键议题、行动项和负责人，形成清晰的结构化记录
- **代码片段**：识别编程语言类型，生成正确的代码块标记
- **网页内容**：去除杂乱格式，提取核心信息

### 3.2 Office 粘贴支持

PasteMD 可作为系统托盘常驻工具，直接从剪贴板读取 Markdown 或网页内容，通过 Pandoc 引擎转换为规范的 DOCX 格式，并自动插入到 Word/WPS 或 Excel 文档的光标位置。

支持从主流 AI 平台（Kimi、DeepSeek、通义千问、豆包、智谱清言、ChatGPT、Gemini、Grok、Claude 等）复制内容并完美转换。


## 4. 安装与启动

### 4.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux / macOS / Windows WSL |
| 内存 | 至少 8GB（推荐 12GB） |
| 存储空间 | 至少 10GB 可用空间 |
| GPU（可选） | 可加速处理速度 |

### 4.2 首次启动

1. 从镜像市场获取 PasteMD 镜像并启动实例
2. 系统自动下载 llama3:8b 模型（约 4.7GB）
3. 根据网络状况，下载可能需要 5-15 分钟
4. 下载完成后自动进入 Web 界面

> **注意**：模型只需下载一次，后续启动为秒级响应。


## 5. 使用方法

### 5.1 基础操作（三步完成）

**第一步：粘贴原始文本**

启动 PasteMD 后，浏览器自动打开 Web 界面，界面为简洁的左右分栏设计：
- 左侧输入框：标题为"粘贴在此处"
- 右侧输出框：显示美化后的 Markdown，支持语法高亮

将需要整理的文本粘贴到左侧输入框中。

**第二步：点击智能美化**

点击中间的"智能美化"按钮，系统自动处理文本：
- 模型分析文本语义
- 自动识别关键信息点
- 确定合适的 Markdown 结构
- 应用标准格式规范

处理时间通常为 1-5 秒。

**第三步：复制美化结果**

右侧输出框显示格式化后的 Markdown 内容，点击右上角"复制"按钮即可一键复制。

### 5.2 Office 粘贴模式（系统托盘版本）

1. 启动 PasteMD 系统托盘工具
2. 复制 Markdown 或网页内容到剪贴板
3. 在 Word/WPS/Excel 中定位到目标光标位置
4. 按下热键（默认 `Ctrl+Shift+B`）
5. 内容自动转换并插入

## 7. 常见问题

### Q1：首次启动为什么需要等待？

首次启动时需要下载 llama3:8b 模型文件（约 4.7GB），下载完成后后续启动为秒级响应。

### Q2：数据会上传到云端吗？

不会。PasteMD 完全在本地运行，所有文本处理都在本地完成，数据不会上传到任何服务器。

### Q3：支持哪些类型的文本？

支持会议记录、网页摘录、代码片段、邮件内容、待办事项、技术文档等几乎所有类型的文本。

### Q4：处理速度如何？

通常在 1-5 秒内完成，复杂文档一般不超过 10 秒。

### Q5：输出质量如何保证？

PasteMD 通过精心设计的"格式化专家"角色提示词，确保模型只做格式整理，不添加多余评论或修改原文意思。
